## 🧭 About the Platform

**[ajitdev.com](https://ajitdev.com)** is the official personal developer platform of **Ajit Dev** — a Full Stack Software Engineer, DevOps Engineer, and Cloud Security Enthusiast from **Katihar, Bihar, India**.

This is not just a portfolio. It is a complete **developer authority platform** — built to showcase technical expertise, document real-world learning, share knowledge with the developer community, and establish a strong personal brand in the Indian tech ecosystem.

> *"Every great developer has a home on the internet. This is mine — built fast, secured deeply, and scaled intentionally."*
> — **Ajit Dev**

## 🔍 SEO Architecture

```
SEO Stack
├── 📄 Dynamic Metadata API (Next.js generateMetadata)
│   ├── Title Templates       → "Ajit Dev | {Page Title}"
│   ├── Meta Descriptions     → Dynamic per page/post
│   └── Canonical URLs        → Prevent duplicate content
│
├── 🌐 Open Graph Protocol
│   ├── og:title, og:description, og:image
│   ├── og:type (website / article)
│   └── Dynamic OG images via @vercel/og
│
├── 🐦 Twitter Cards
│   ├── twitter:card = summary_large_image
│   └── twitter:creator = @ajitdev01
│
├── 🔢 JSON-LD Structured Data
│   ├── Person Schema         → Ajit Dev personal identity
│   ├── BlogPosting Schema    → Every blog post
│   ├── FAQ Schema            → FAQ sections
│   ├── BreadcrumbList Schema → All nested routes
│   └── WebSite Schema        → Sitewide identity
│
├── 🗺️ Technical SEO
│   ├── sitemap.xml           → Auto-generated, all routes included
│   ├── robots.txt            → Crawl directives for all bots
│   └── RSS Feed              → Blog RSS for feed aggregators
│
└── 📊 Search Console
    └── Indexed & monitored via Google Search Console
```

### Performance Strategies

- ✅ **Image optimization** via `next/image` with WebP/AVIF & lazy loading
- ✅ **Font optimization** via `next/font` — zero layout shift
- ✅ **Code splitting** — automatic per-route via App Router
- ✅ **Static generation (SSG)** for all blog, DSA, and system design pages
- ✅ **Incremental Static Regeneration (ISR)** for dynamic content
- ✅ **Edge caching** via Vercel's global CDN network
- ✅ **Bundle analysis** with `@next/bundle-analyzer`
- ✅ **Prefetching** on `<Link>` for instant page transitions

## 🚀 Getting Started

### Prerequisites

```bash
node  >= 20.x
npm   >= 10.x   (or pnpm / yarn)
git   >= 2.x
```

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/ajitdev01/ajitdev.com.git
cd ajitdev.com

# 2. Install dependencies
npm install

# 3. Set up environment variables
cp .env.example .env.local
```

### Environment Variables

```env
# .env.local

# Site
NEXT_PUBLIC_SITE_URL=https://ajitdev.com

# Analytics
NEXT_PUBLIC_GA_MEASUREMENT_ID=G-XXXXXXXXXX
NEXT_PUBLIC_GTM_ID=GTM-XXXXXXX

# Contact Form
CONTACT_EMAIL=ajitk23192@gmail.com
RESEND_API_KEY=re_XXXXXXXXXXXX

# Optional
NEXT_PUBLIC_CLARITY_ID=XXXXXXXXX
```

### Development

```bash
# Start development server (Turbopack)
npm run dev

# Open in browser
http://localhost:3000
```

### Production Build

```bash
# Build for production
npm run build

# Analyze bundle size
npm run build:analyze

# Start production server
npm run start

# Run linter
npm run lint

# Type check
npm run type-check
```
